# ICASSP 2027 paper files

- `ICASSP2027_ParaGeo_draft.tex`: selectable title/abstract/introduction drafts plus the recommended Experimental Setup.
- `icassp2027_parageo_refs.bib`: references used by the draft.
- `generated/`: created automatically by `scripts/summarize_icassp2027.py` after experiments finish.

For Overleaf, start from the official ICASSP 2027 template supplied by the conference/user, keep its `spconf.sty` and `IEEEbib.bst`, and replace the template `.tex` with `ICASSP2027_ParaGeo_draft.tex`. Upload `icassp2027_parageo_refs.bib` and, after experiments, the generated `.tex` files.

The fifth page is references only. Keep ablations/mechanism analysis inside the four content pages.
