# Manuscript files

[Back to ParaGeo](../README.md)

This directory contains historical manuscript drafts and generated LaTeX tables from the experiment workflow. Files with different titles or placeholder macros document earlier writing stages; they are **not labeled as the final five-page submission**.

Historical files include `ICASSP2027_ParaGeo_draft.tex`, `icassp2027_parageo_refs.bib`, and the `generated/` outputs produced by `scripts/summarize_icassp2027.py`.

The current research title is **ParaGeo: Decomposing Paralinguistic Variation into a Shared Latent Geometry**. The author order is **Yuhan Liu, Yuxuan Ou, Ruoxi Su, Mohamed Ahmed Zaki, Yunbo Long**.

Use the [results guide](../docs/PARAGEO_RESULTS.md) to interpret saved measurements and the [reproduction guide](../docs/PARAGEO_REPRODUCIBILITY.md) to find the corresponding code. Generating old LaTeX templates does not validate every claim in an earlier draft.

No DOI, arXiv paper link, or conference-acceptance status is asserted by this repository entry. Bibliographic software metadata is available in [CITATION.cff](../CITATION.cff).
